# AASTU Study Planner — Version 7

This update adds a local multiple-choice practice-test builder, test scoring, and a mistake-review list.

## Update on GitHub Pages
1. Back up your current planner from Reviews & backup.
2. Extract this ZIP.
3. Upload the extracted files and folders to the root of your existing GitHub repository, replacing the previous versions.
4. Commit changes to `main`. GitHub Pages should redeploy automatically.
5. Refresh the live site. If the old version appears, close the page and reopen it or clear the site's cached data only after backing up.

## Notes
- Quiz questions, answers, and attempts are stored in browser local storage on this device.
- This is a self-study tool, not an official exam or remotely synchronized service.
- Export JSON backups regularly.
- Keep the `icons` folder and all project files in the repository root structure.
